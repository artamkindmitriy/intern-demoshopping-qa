# intern-demoshopping-qa

Репозиторий с тестовой документацией и артефактами проверки веб-приложения интернет-магазина. Проект организован по спринтам, каждый из которых отражает этап тестирования.

---

## 🛠 Стек и инструменты
* **Test Management:** Test IT (проектирование тест-кейсов, сьютов и проведение прогонов)
* **Bug Tracking:** Jira (декомпозиция требований в User Stories, заведение и трекинг дефектов)
* **Documentation:** Confluence (тест-план, итоговый отчёт)
* **Checklists & Analytics:** Google Sheets (чек-листы)
* **DevTools:** Chrome DevTools (анализ консоли и сетевых запросов)

## Sprint 01: Функциональное тестирование (`Build 1.0`)

Проверка базового пользовательского пути: регистрация, авторизация, просмотр каталога и карточки товара, работа корзины, фильтрация и сортировка.

### 📊 Метрики прогона
* **Оценка трудозатрат:** $7,3 \pm 0,6$ ч (фактически затрачено: 10 ч)
* **Покрытие:** 56 проверок в чек-листах / 40 тест-кейсов
* **Результаты выполнения:** ✅ Passed: **25** (63%) | ❌ Failed: **11** (28%) | ⏭ Skipped: **4** (10%)
* **Выявлено дефектов:** **11 багов** (High: 6, Medium: 4, Low: 1)
* **Статус релиза:** 🔴 **Не рекомендован к продакшену** (требуется исправление High-дефектов)

### 📂 Навигация по артефактам
1. **Тест-план (Test Plan)** – цели, область тестирования, риски, стратегия и оценка трудозатрат.  
   📄 [Тест-план.pdf](./Sprint_01_Functional_Testing/01_Test_Plan/Тест-план.pdf)
2. **Требования (User Stories)** – реестр декомпозированных требований (`US-1` – `US-8`) со ссылками на карточки в Jira.  
   📋 [Реестр User Stories](./Sprint_01_Functional_Testing/02_Requirments/README.md)
3. **Чек-листы (Checklists)** – 56 проверок, сгруппированных по пользовательским историям.  
   📁 [Папка с чек-листами (PDF)](./Sprint_01_Functional_Testing/03_Checklists/)
4. **Тест-кейсы (Test Cases)** – 40 детальных тест-кейсов по модулям (авторизация, регистрация, каталог, фильтрация, сортировка).  
   📁 [Папка с тест-кейсами (PDF)](./Sprint_01_Functional_Testing/04_Test_Cases/)
5. **Баг-репорты (Bug Reports)** – реестр из 11 дефектов (`ID-10` – `ID-20`) с приоритетами и ссылками на Jira.  
   🐞 [Реестр дефектов](./Sprint_01_Functional_Testing/05_Bug_Reports/README.md)
6. **Итоговый отчёт (Test Summary Report)** – сводные метрики, матрица трассируемости и рекомендации по релизу.  
   📄 [Отчёт о тестировании.pdf](./Sprint_01_Functional_Testing/06_Test_Summary_Report/Отчёт%20о%20тестировании.pdf)
